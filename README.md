# Beginner GitHub Pages Demo

This project is a very small website created to demonstrate the basics of GitHub.

The site contains:

- `index.html`: the words and image shown on the webpage
- `styles.css`: simple controls for colors, font, alignment, and image size
- `tree.svg`: the tree image displayed on the webpage

## Demo goal

We will publish the website with GitHub Pages. Then a colleague will create a branch, make a small change, and open a pull request. After the pull request is reviewed and merged, the public website will update.

## Easy changes to try

1. Open `index.html` and change the sentence inside a `<p>` tag.
2. Open `styles.css` and change `lightblue`, `darkgreen`, or `navy` to another color.
3. Commit the change and open a pull request.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `tree.svg` to the repository root.
3. Open **Settings** in the repository.
4. Select **Pages** under **Code and automation**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then select **Save**.
7. Wait a minute or two. GitHub will show the public website link on the Pages settings screen.
